🟢 COLAB DEMO

วิเคราะห์ความรู้สึกทีละรีวิว

from transformers import pipeline
 
sentiment = pipeline("sentiment-analysis")
 
texts = [
    "This food is amazing! Best restaurant ever!",
    "Terrible service. I waited 2 hours for cold food.",
    "The movie was okay, nothing special.",
]
 
for text in texts:
    result = sentiment(text)[0]
    print(f"{text}")
    print(f"  → {result['label']} ({result['score']:.1%})")
    print()
This food is amazing! Best restaurant ever! → POSITIVE (99.3%) Terrible service. I waited 2 hours for cold food. → NEGATIVE (98.7%) The movie was okay, nothing special. → POSITIVE (61.2%)
PIPELINEเปลี่ยนแค่ชื่องาน ได้ AI คนละแบบ
[0]เอาผลแรก: label + score

🟢 COLAB DEMO · Text Generation

เรียก GPT-2 มาเขียนต่อ

from transformers import pipeline
 
# GPT-2 คือ model รุ่นเก่า (2019) เล็กกว่า ChatGPT มาก
# แต่หลักการเดียวกันเลยครับ — ทำนายคำถัดไป
generator = pipeline("text-generation", model="gpt2")
print("✅ พร้อมแล้วครับ!")

🟢 COLAB DEMO · Text Generation

ให้ AI เขียนต่อจาก prompt

# ให้ AI เขียนต่อจาก prompt นี้
prompt = "Once upon a time, a cat decided to"
result = generator(prompt, max_length=50)
 
print("Prompt:", prompt)
print("AI เขียนต่อว่า:")
print(result[0]["generated_text"])
