# ทำ go-module ไว้ใช้เองกันครับ

ก่อนอื่นเราสร้าง project กันก่อนเลย

**mkdir**go-module-utils
และเราก็ใช้คำสั่ง go init เพื่อ init go ขึ้นมา โดยใช้ชื่อ repository url ใน github ของเรา

**go** mod init {repository_github_url}/[go-module-utils](https://github.com/nanpipat-dev/go-module-utils)
จากนั้นสร้างไฟล์ main.go

![Image 1](https://miro.medium.com/v2/resize:fit:700/1*Si-E-geVCpvG0lYnoH_25g.png)

และเราก็จะสร้าง module ขึ้นมา โดยผมจะแยกออกมาเป็น module ละโฟลเดอร์เลยนะครับ

> _project structure จะประมาณนี้_

.  
├── pointer2value  
│ └── pointer2value.go  
│ └── pointer2value_test.go  
├── main.go

![Image 2](https://miro.medium.com/v2/resize:fit:700/1*7aF39DivsofssfvmdUi0fQ.png)

ทำ function ที่เราจะนำไปใช้งาน

![Image 3](https://miro.medium.com/v2/resize:fit:700/1*_5PmQDgMzQtiX8NE36SmYg.png)

เขียน test สักหน่อยเผื่อความสวยงาม (optional)

เมื่อทำเสร็จ ก็ได้เวลาเอาขึ้น github ครับ

![Image 4](https://miro.medium.com/v2/resize:fit:700/1*cBs_tY7h9wOy0FekHvAEbA.jpeg)

สร้าง project ขึ้นมา โดยอันนี้ผมจะทำแบบ public นะครับ วิธีทำแบบ private เดี๋ยวจะแปะลิ้งไว้ให้

เรียบร้อยแล้วก็ commit/push โค้ดของเราขึ้นไปเล้ยยยยยยย

![Image 5](https://miro.medium.com/v2/resize:fit:700/1*-Z0_wRx9Z7-Xuw7nem-ZsA.jpeg)

ต่อไปมาทำ tag version กันครับ

![Image 6](https://miro.medium.com/v2/resize:fit:580/1*a85n_uNXqHtfIn51OCZZVA.jpeg)

เท่านี้ก็เรียบร้อยแล้วครับบบ

เดี๋ยวเราลองมาทดสอบกันครับ

ผมสร้าง project ขึ้นมาใหม่เพื่อเทส และ go get package ของเรามานะครับ ด้วยคำสั่ง

**go** get github.com/nanpipat-dev/go-module-utils@v1.0.0
มาทดสอบเรียกใช้กันหน่อยครับ

![Image 7](https://miro.medium.com/v2/resize:fit:700/1*tVN5cmRowptV2r23GJtxmg.png)

ลองรันดูครับ

![Image 8](https://miro.medium.com/v2/resize:fit:700/1*jiMhE7f51L_UGAjX5bmf2w.jpeg)

เรียบร้อย ผลลัพท์ก็ออกมาตามที่เราเรียกใช้ go package ของเราอย่างงดงามครับบ
