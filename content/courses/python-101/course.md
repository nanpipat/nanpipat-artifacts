## จากคนที่มองโค้ดเหมือนอักษรลับ สู่คนที่สั่งคอมพิวเตอร์ทำงานเองได้

เช้าวันแรกของการเรียนเขียนโปรแกรม หน้าจอว่างเปล่ามักดูน่ากลัวกว่าที่ควรจะเป็น

เคอร์เซอร์กะพริบเหมือนกำลังถามว่า “จะพิมพ์อะไรล่ะ?” ส่วนคนหน้าจอก็คิดกลับว่า “ถ้ารู้จะมานั่งเรียนทำไมล่ะ?”

ข่าวดีคือโปรแกรมแรกของเราไม่ต้องเป็นเกม ไม่ต้องเป็น AI และไม่ต้องช่วยโลกจากอุกกาบาต แค่ทำให้คอมพิวเตอร์พิมพ์ข้อความหนึ่งบรรทัดออกมาก็ถือว่าเราเริ่มสื่อสารกับมันได้แล้ว

```python
print("Hello World")
```

กด Run แล้วเห็นคำว่า `Hello World` ปรากฏขึ้นมา นั่นอาจดูเป็นเหตุการณ์เล็ก ๆ แต่ความหมายของมันใหญ่กว่านั้น เราเพิ่งเขียนคำสั่ง และเครื่องทำตามคำสั่งของเราอย่างตรงไปตรงมา

ตรงไปตรงมามากจนถ้าเราพิมพ์ผิด มันก็พังอย่างตรงไปตรงมาเช่นกัน

บทความนี้พาเดินตั้งแต่ Python คืออะไร ไปจนถึงตัวแปร ชนิดข้อมูล ตัวดำเนินการ เงื่อนไข Loop, Input และ Function พร้อมตัวอย่างที่เอาไปลองต่อได้ทันที

## 1. Python คืออะไร และทำไมคนเริ่มต้นถึงมักเจอมันก่อน

Python เป็นภาษาการเขียนโปรแกรมระดับสูง หรือ High-level Programming Language

คำว่า “ระดับสูง” ไม่ได้หมายถึงเนื้อหายากหรือเอาไว้ให้โปรแกรมเมอร์อาวุโสใช้ มันหมายถึงภาษาที่เขียนใกล้กับวิธีสื่อสารของมนุษย์มากกว่าภาษาเครื่อง

ลองดูงานง่าย ๆ อย่างการบวกเลข 5 กับ 3

ภาษา Assembly อาจต้องระบุว่าจะนำตัวเลขไปเก็บตรงไหน แล้วค่อยสั่งให้เครื่องบวกค่าในตำแหน่งเหล่านั้น

```asm
MOV AX, 5
MOV BX, 3
ADD AX, BX
```

Python เขียนสั้นกว่ามาก

```python
print(5 + 3)
```

ทั้งสองแบบกำลังคุยกับคอมพิวเตอร์เหมือนกัน เพียงแต่ Python มีล่ามที่ช่วยแปลความตั้งใจของเราให้เครื่องเข้าใจ จึงอ่านง่ายและทดลองได้เร็ว

### ภาษาที่รันแล้วเห็นผลทันที

Python ทำงานแบบ Interpreted Language ในภาพรวม เราเขียนคำสั่งแล้วให้ Python interpreter ประมวลผลได้เลย เหมือนมีล่ามนั่งข้าง ๆ คอยแปลทีละช่วง

ภาษาที่ต้อง Compile เปรียบเหมือนส่งหนังสือทั้งเล่มไปแปลก่อนจึงค่อยอ่าน ส่วน Python เหมือนล่ามแปลให้ฟังระหว่างสนทนา

ข้อดีสำหรับผู้เริ่มต้นคือวงรอบการเรียนสั้นมาก

1. พิมพ์โค้ด
2. กด Run
3. เห็นผลหรือเห็น Error
4. แก้แล้วลองใหม่

Error จึงไม่ใช่ใบแดงที่บอกว่าเราไม่เหมาะกับการเขียนโปรแกรม มันเป็นข้อความจากคอมพิวเตอร์ที่บอกว่า “ผมตามไม่ทันตรงนี้ ช่วยอธิบายใหม่หน่อย”

### Python ใช้ทำอะไรได้บ้าง

Python ไปโผล่ในงานหลายประเภท เพราะอ่านง่ายและมี Library ให้ใช้จำนวนมาก

- สร้างเว็บไซต์และ API
- วิเคราะห์ข้อมูลและสร้างกราฟ
- พัฒนา Machine Learning และ AI
- ทำงานซ้ำ ๆ ให้เป็น Automation
- เขียนโปรแกรมควบคุมอุปกรณ์
- สร้างเครื่องมือเล็ก ๆ สำหรับงานประจำวัน

Library เปรียบเหมือนกล่องเครื่องมือสำเร็จรูป ถ้าต้องตอกตะปู เราไม่จำเป็นต้องถลุงแร่แล้วหล่อค้อนเอง มีคนทำค้อนมาให้แล้ว เราเพียงเรียนรู้ว่าจะหยิบอันไหนและใช้อย่างไร

> **ภาพจำแบบเร็ว:** Python อ่านง่ายพอให้มือใหม่เริ่มได้ และมีเครื่องมือมากพอให้คนทำงานจริงใช้ต่อได้อีกไกล

## 2. จะเขียน Python ที่ไหนดี

ผู้เริ่มต้นมักเจอสองทางเลือกหลัก

### Google Colab สำหรับทดลองทันที

Google Colab เปิด Notebook บน browser และรันโค้ดแยกเป็น Cell ได้ เหมาะกับการเรียน ทดลอง และ Demo เพราะไม่ต้องตั้งค่าเครื่องมาก

เปิด Notebook ใหม่ พิมพ์โค้ด แล้วกด `Shift + Enter`

```python
print("สวัสดี Python")
print(5 + 3)
```

ถ้าเห็นผลลัพธ์สองบรรทัด แสดงว่าพื้นที่ทดลองพร้อมแล้ว

Notebook ให้ความรู้สึกเหมือนสมุดทดลอง เรารันทีละ Cell แก้บางส่วน แล้วดูผลได้ทันที แต่ต้องจำว่าสถานะของตัวแปรจะค้างอยู่ใน Session ถ้ารัน Cell สลับลำดับ บางครั้งผลอาจทำให้เรางงได้

### Python และ VS Code สำหรับทำโปรเจกต์บนเครื่อง

เมื่อเริ่มทำงานเป็นไฟล์จริง เรามักติดตั้ง Python และใช้โปรแกรมเขียนโค้ด เช่น VS Code

ขั้นตอนภาพรวมมีดังนี้

1. ติดตั้ง Python จากเว็บไซต์ทางการ

3. ติดตั้ง VS Code
4. ติดตั้งส่วนเสริม Python และ Jupyter
5. สร้างไฟล์ `main.py`
6. รันด้วย `python main.py`

บน Windows ระหว่างติดตั้งควรสังเกตตัวเลือกเพิ่ม Python ลงใน PATH เพราะ PATH ทำให้ Terminal รู้ว่าจะไปหาโปรแกรม Python ที่ไหน

ไฟล์ `.py` เหมาะกับโปรแกรมที่ต้องรันเป็นชุด ส่วน `.ipynb` เหมาะกับการเรียน การสำรวจข้อมูล และการทดลองทีละ Cell

> **มือใหม่ไม่ต้องเลือกข้าง:** เริ่มใน Colab ให้คล่อง แล้วค่อยย้ายไปไฟล์ `.py` เมื่ออยากจัดโปรเจกต์ให้เป็นระเบียบ

## 3. Variable กล่องติดป้ายที่เก็บข้อมูลให้เรา

ลองนึกว่าบนโต๊ะมีของหลายชิ้น ถ้าวางกองรวมกัน เราต้องรื้อทุกครั้งที่อยากหยิบ แต่ถ้าใส่กล่องและติดป้ายว่า “ใบเสร็จ”, “สายชาร์จ” และ “ขนมที่ห้ามเพื่อนกิน” การเรียกใช้จะง่ายขึ้น

ตัวแปร หรือ Variable ทำหน้าที่คล้ายกล่องติดป้าย

```python
name = "Mali"
age = 20
height = 1.62
is_student = True
```

เครื่องหมาย `=` ตรงนี้หมายถึงการกำหนดค่า ฝั่งขวาคือข้อมูลที่นำไปเก็บ ฝั่งซ้ายคือชื่อที่เราจะใช้เรียกข้อมูลนั้นภายหลัง

```python
print(name)
print(age)

age = 21
print(age)
```

ตัวแปรเปลี่ยนค่าได้ จึงเรียกว่า Variable ถ้าเราใส่ค่าใหม่ในกล่องเดิม ค่าก่อนหน้าก็ถูกแทนที่

### ตั้งชื่ออย่างไรให้ตัวเองในอนาคตไม่โกรธ

ชื่ออย่าง `x`, `a1`, `tmp2` เขียนเร็ว แต่คนที่กลับมาอ่านอีกเดือนอาจต้องเล่นเกมทายใจตัวเอง

ชื่อที่ดีบอกความหมายของข้อมูล

```python
student_name = "Mali"
total_price = 450
is_logged_in = False
```

Python นิยมรูปแบบ `snake_case` ใช้ตัวพิมพ์เล็กและ `_` คั่นคำ

กฎสำคัญมีไม่กี่ข้อ

- ห้ามขึ้นต้นด้วยตัวเลข
- ห้ามมีช่องว่าง
- ตัวพิมพ์ใหญ่กับเล็กถือเป็นคนละชื่อ
- หลีกเลี่ยงคำที่ Python ใช้เป็นคำสั่ง เช่น `if`, `for`, `class`

`name` และ `Name` เป็นคนละตัวแปร คอมพิวเตอร์ไม่รู้ว่าเรากด Shift พลาด มันคิดว่าเราตั้งใจสร้างคนละชื่อจริง ๆ

## 4. Data Type ของในกล่องเป็นคนละชนิดกัน

ตัวแปรเป็นกล่อง ส่วน Data Type บอกว่าของในกล่องคืออะไร

### ตัวเลขจำนวนเต็มด้วย `int`

```python
age = 20
temperature = -5
year = 2026
```

### ตัวเลขทศนิยมด้วย `float`

```python
height = 1.62
price = 99.50
```

### ข้อความด้วย `str`

```python
name = "Mali"
phone = "0812345678"
```

หมายเลขโทรศัพท์หน้าตาเหมือนตัวเลข แต่เราไม่ได้เอาไปบวกหรือลบ และเลขศูนย์ด้านหน้ามีความหมาย จึงควรเก็บเป็นข้อความ

### ค่าจริงหรือเท็จด้วย `bool`

```python
is_student = True
has_discount = False
```

`True` และ `False` ต้องขึ้นต้นด้วยตัวพิมพ์ใหญ่

### ข้อมูลหลายชิ้นด้วย Collection

`list` เก็บข้อมูลเป็นลำดับและแก้ไขได้

```python
fruits = ["apple", "banana", "mango"]
scores = [85, 92, 78]
```

`tuple` คล้าย List แต่ไม่เปิดให้แก้ค่าแบบเดิม เหมาะกับข้อมูลที่ต้องการสื่อว่าไม่ควรเปลี่ยน

```python
bangkok = (13.7563, 100.5018)
```

`dict` เก็บข้อมูลแบบ Key และ Value

```python
student = {
    "name": "Mali",
    "score": 92,
    "passed": True,
}
```

`set` เก็บสมาชิกไม่ซ้ำและไม่ได้เน้นลำดับ

```python
visitors = {"Ann", "Bob", "Ann", "Mali"}
print(visitors)
```

ตรวจชนิดข้อมูลด้วย `type()`

```python
print(type(25))       # int
print(type(1.75))     # float
print(type("25"))    # str
print(type(True))     # bool
```

สังเกตว่า `25` กับ `"25"` หน้าตาคล้ายกันสำหรับคน แต่ Python เห็นคนละชนิด ตัวแรกคำนวณได้ ตัวหลังคือข้อความสองตัวอักษร

> **กับดักยอดนิยม:** ถ้า Python บ่นว่าบวกตัวเลขกับข้อความไม่ได้ ให้ดู Data Type ก่อนสงสัยว่าคอมพิวเตอร์มีอคติกับเรา

## 5. Operators เครื่องหมายที่ทำให้ข้อมูลเริ่มขยับ

เมื่อมีข้อมูลแล้ว เราต้องมีวิธีคำนวณ เปรียบเทียบ และเชื่อมเงื่อนไข

### Arithmetic Operators

```python
print(10 + 3)   # 13
print(10 - 3)   # 7
print(10 * 3)   # 30
print(10 / 3)   # 3.333...
print(10 // 3)  # 3
print(10 % 3)   # 1
print(2 ** 10)  # 1024
```

`%` หรือ Modulus หารเอาเศษ จึงใช้ตรวจเลขคู่ได้

```python
number = 14
is_even = number % 2 == 0
print(is_even)
```

### Comparison Operators

ผลลัพธ์ของการเปรียบเทียบคือ Boolean

```python
age = 20

print(age == 20)  # เท่ากันหรือไม่
print(age != 18)  # ไม่เท่ากันหรือไม่
print(age > 17)
print(age <= 20)
```

มือใหม่มักสลับ `=` กับ `==`

- `=` ใช้กำหนดค่า
- `==` ใช้ถามว่าสองค่าเท่ากันหรือไม่

### Logical Operators

```python
age = 20
has_ticket = True

can_enter = age >= 18 and has_ticket
print(can_enter)
```

- `and` ต้องจริงทั้งสองฝั่ง
- `or` จริงเพียงฝั่งหนึ่งก็พอ
- `not` กลับค่าจริงเป็นเท็จ หรือเท็จเป็นจริง

ลองนึกถึงประตูงานคอนเสิร์ต เงื่อนไขอาจบอกว่าต้องอายุถึง **และ** มีบัตร ส่วนโปรโมชั่นอาจบอกว่าเป็นสมาชิก **หรือ** มีคูปองก็รับส่วนลดได้

## 6. Control Structure ทำให้โปรแกรมเลือกทางและทำซ้ำได้

ถ้าโปรแกรมทำงานจากบนลงล่างอย่างเดียว มันจะคล้ายพนักงานที่อ่าน checklist แล้วทำทุกข้อโดยไม่ดูสถานการณ์ Control Structure ช่วยให้โปรแกรมเลือกและวนซ้ำได้

### `if`, `elif`, `else` สำหรับการตัดสินใจ

```python
score = 82

if score >= 80:
    grade = "A"
elif score >= 70:
    grade = "B"
elif score >= 60:
    grade = "C"
else:
    grade = "F"

print(grade)
```

Python ใช้การเยื้องบรรทัด หรือ Indentation เพื่อบอกว่าโค้ดส่วนไหนอยู่ใต้เงื่อนไข หากเยื้องผิด โปรแกรมอาจ Error หรือทำงานคนละแบบกับที่คิด

ลำดับเงื่อนไขก็สำคัญ ถ้าตรวจ `score >= 60` ก่อน `score >= 80` คะแนน 95 จะผ่านเงื่อนไขแรกและหยุดทันที จึงต้องวางเงื่อนไขจากเฉพาะหรือเข้มกว่าไปหาเงื่อนไขกว้างกว่า

### `for` สำหรับวนผ่านสิ่งที่รู้จำนวนหรือรายการ

```python
fruits = ["apple", "banana", "mango"]

for fruit in fruits:
    print("ฉันชอบ", fruit)
```

ใช้ `range()` เมื่อต้องการชุดตัวเลข

```python
for number in range(1, 6):
    print(number)
```

`range(1, 6)` ได้ 1 ถึง 5 เพราะค่าปลายทางไม่ถูกรวมอยู่ด้วย จุดนี้ทำให้มือใหม่รู้สึกเหมือน Python แอบกินเลข 6 ไป แต่จริง ๆ มันทำตามกติกาเดิมทุกครั้ง

### `while` สำหรับวนตราบใดที่เงื่อนไขยังจริง

```python
countdown = 3

while countdown > 0:
    print(countdown)
    countdown -= 1

print("เริ่ม!")
```

ต้องมีสิ่งที่ทำให้เงื่อนไขเปลี่ยน ไม่เช่นนั้นจะเกิด Infinite Loop โปรแกรมวิ่งรอบเดิมเหมือนคนเดินบนลู่วิ่งแต่ลืมปุ่มหยุด

## 7. Input เปลี่ยนโปรแกรมจากการพูดคนเดียวเป็นบทสนทนา

ก่อนมี Input โปรแกรมใช้ค่าที่เราเขียนไว้ล่วงหน้า เมื่อใช้ `input()` ผู้ใช้สามารถส่งข้อมูลเข้ามาระหว่างรันได้

```python
name = input("คุณชื่ออะไร: ")
print("สวัสดี", name)
```

เรื่องสำคัญคือ `input()` คืนค่าเป็น String เสมอ แม้ผู้ใช้พิมพ์ตัวเลข

```python
age_text = input("อายุเท่าไร: ")
print(type(age_text))
```

ถ้าต้องคำนวณ ต้องแปลงชนิดก่อน

```python
age = int(input("อายุเท่าไร: "))
next_year = age + 1
print("ปีหน้าคุณจะอายุ", next_year)
```

### Mini Project คำนวณ BMI

```python
weight = float(input("น้ำหนักกิโลกรัม: "))
height = float(input("ส่วนสูงเมตร: "))

bmi = weight / (height ** 2)
print(f"BMI ของคุณคือ {bmi:.2f}")

if bmi < 18.5:
    print("ต่ำกว่าเกณฑ์")
elif bmi < 23:
    print("อยู่ในช่วงทั่วไป")
elif bmi < 25:
    print("เริ่มสูง")
else:
    print("สูง")
```

ตัวอย่างนี้ทำให้เห็นว่าความรู้หลายส่วนเริ่มต่อกันแล้ว เรารับ Input, แปลง Data Type, ใช้ Operator คำนวณ และใช้เงื่อนไขเลือกข้อความ

ในโปรแกรมจริงควรตรวจว่าผู้ใช้กรอกค่าถูกต้องด้วย เพราะผู้ใช้มีพลังพิเศษในการพิมพ์คำว่า “หกสิบ” ลงในช่องที่โปรแกรมรอเลข `60`

## 8. Function สร้างเครื่องมือของเราเอง

เมื่อโค้ดเริ่มยาว เราจะพบประโยคที่ต้องเขียนซ้ำ Function ช่วยรวมงานหนึ่งชุด ตั้งชื่อ แล้วเรียกใช้ภายหลัง

```python
def greet(name):
    message = f"สวัสดี {name}"
    return message

print(greet("Mali"))
print(greet("Nina"))
```

ส่วนประกอบสำคัญมีดังนี้

- `def` บอกว่าเรากำลังนิยาม Function
- `greet` คือชื่อ
- `name` คือ Parameter ที่รับเข้ามา
- `return` ส่งผลลัพธ์กลับ

การนิยาม Function เหมือนเขียนสูตรไว้ การเรียก Function จึงเหมือนหยิบสูตรนั้นมาใช้กับวัตถุดิบรอบนี้

### ระบบตัดเกรดด้วย Function

```python
def calculate_grade(score):
    if score >= 80:
        return "A"
    if score >= 70:
        return "B"
    if score >= 60:
        return "C"
    if score >= 50:
        return "D"
    return "F"


students = {
    "Mali": 82,
    "Nina": 74,
    "Ton": 48,
}

for name, score in students.items():
    grade = calculate_grade(score)
    print(f"{name}: {score} คะแนน ได้เกรด {grade}")
```

Function ทำให้กติกาการตัดเกรดอยู่จุดเดียว ถ้าวันหนึ่งเกณฑ์เปลี่ยน เราแก้ที่ Function แทนการไล่แก้หลายตำแหน่ง

> **สัญญาณว่าควรสร้าง Function:** โค้ดชุดเดิมเริ่มโผล่ซ้ำ หรือเราสามารถอธิบายงานช่วงหนึ่งด้วยชื่อสั้น ๆ เช่น `calculate_grade()` หรือ `print_receipt()`

## 9. Error สามแบบที่มือใหม่ต้องได้เจอ

อย่าตั้งเป้าว่าจะเขียนโปรแกรมโดยไม่เจอ Error เพราะแม้แต่คนเขียนมานานก็เจอ เป้าหมายที่มีประโยชน์กว่าคืออ่าน Error แล้วเริ่มสืบหาได้

### Syntax Error

โครงสร้างภาษาไม่ถูก เช่น ลืม `:` หลัง `if`

```python
if age >= 18
    print("ผ่าน")
```

### Name Error

เรียกชื่อตัวแปรที่ยังไม่มี หรือสะกดไม่ตรง

```python
student_name = "Mali"
print(studen_name)
```

### Type Error

นำข้อมูลคนละชนิดมาทำงานที่เข้ากันไม่ได้

```python
age = "20"
print(age + 1)
```

เวลาเจอ Error ให้เริ่มจากบรรทัดท้ายของข้อความ อ่านชื่อ Error และดูเลขบรรทัดก่อน การอ่านข้อความทั้งหมดจากบรรทัดแรกอาจให้ความรู้สึกเหมือนเปิดนิยายจากบทที่ผู้ร้ายอธิบายประวัติครอบครัว ทั้งที่คำใบ้สำคัญอยู่บรรทัดสุดท้าย

## 10. แบบฝึกหัดปิดบท โปรแกรมรับคะแนนและสรุปผล

ลองรวม Variable, Input, Type Conversion, Function และเงื่อนไขเข้าด้วยกัน

```python
def calculate_grade(score):
    if score >= 80:
        return "A"
    elif score >= 70:
        return "B"
    elif score >= 60:
        return "C"
    elif score >= 50:
        return "D"
    return "F"


name = input("ชื่อนักเรียน: ")
score = float(input("คะแนน: "))

if 0 <= score <= 100:
    grade = calculate_grade(score)
    print(f"{name} ได้ {score:.1f} คะแนน เกรด {grade}")
else:
    print("คะแนนต้องอยู่ระหว่าง 0 ถึง 100")
```

จากโปรแกรมนี้ ลองเพิ่มความสามารถด้วยตัวเอง

1. รับนักเรียนหลายคนด้วย Loop
2. เก็บผลลัพธ์ใน List หรือ Dictionary
3. หาคะแนนเฉลี่ย
4. แสดงคนที่ได้คะแนนสูงสุด
5. ถ้าผู้ใช้กรอกข้อความแทนตัวเลข ให้โปรแกรมแจ้งเตือนโดยไม่ปิดตัวทันที

ทุกข้อทำให้โปรแกรมขยับจากแบบฝึกหัดไปใกล้เครื่องมือจริงขึ้นอีกนิด

## สรุป Python 101

ตอนเริ่มต้น เรามีเพียงหน้าจอว่างกับเคอร์เซอร์ที่กะพริบ ตอนนี้เรารู้แล้วว่าจะเก็บข้อมูลอย่างไร คำนวณ เปรียบเทียบ เลือกทาง วนซ้ำ รับคำตอบจากผู้ใช้ และจัดโค้ดเป็น Function ได้

เส้นทางทั้งหมดเชื่อมกันแบบนี้

```text
ข้อมูลเข้ามา
  ↓
เก็บในตัวแปรและ Data Type ที่เหมาะสม
  ↓
ใช้ Operator คำนวณหรือเปรียบเทียบ
  ↓
ใช้ Condition และ Loop ควบคุมการทำงาน
  ↓
จัดงานที่ใช้ซ้ำเป็น Function
  ↓
แสดงผลลัพธ์กลับไปให้ผู้ใช้
```

ความคล่องไม่ได้เกิดจากการอ่าน Syntax จบหนึ่งรอบ มันเกิดจากการเขียนโค้ดสั้น ๆ ให้พัง แก้ให้รัน แล้วค่อยเพิ่มความสามารถทีละชิ้น

เริ่มจากโปรแกรมเล็กพอที่เรายังมองเห็นทั้งตัว แล้วพรุ่งนี้เพิ่มอีกหนึ่งอย่าง ไม่นานหน้าจอว่างที่เคยน่ากลัวจะกลายเป็นพื้นที่ที่เรารู้ว่าจะเริ่มตรงไหน
