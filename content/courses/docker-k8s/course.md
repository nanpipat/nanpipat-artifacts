# Docker & Kubernetes — Internal Training

คอร์สอบรมภายในองค์กร ความยาว **2 วัน** ออกแบบให้ทีม dev เดินจาก "รัน container เป็น" ไปจนถึง "ดูแล workload บน Kubernetes ได้จริง"

## Day 1 — Docker

- Docker คืออะไร ทำไมต้องรู้ (ด้วย analogy โรงอาหาร container 🚢)
- คำสั่ง Docker พื้นฐานที่ใช้บ่อย
- Docker Image เบื้องต้น
- Docker Compose
- Workshop: ฝึก diagnose ปัญหาจากเคสจริง

## Day 2 — Kubernetes & Rancher

- Kubernetes คืออะไร ทำไมต้องมี
- โครงสร้างพื้นฐานที่ต้องรู้จัก (Pod, Deployment, Service)
- การ deploy และจัดการ workload ด้วย Rancher

## เอกสารประกอบ

- สไลด์ Day 1 และ Day 2 เปิดดูได้จากด้านล่าง (พรีวิวได้ในหน้าเว็บ หรือกดเปิดเต็มจอ)
- ไฟล์ PPTX ดาวน์โหลดได้ พร้อม lab setup yaml และชุดคำถาม pre/post-test
